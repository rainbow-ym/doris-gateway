# 账号管理 SQL 自动同步（2026.10.15-accounts.1）

## 范围与使用

通过已接入的 Doris root 连接网关，并选择一个已接入数据库。该逻辑库对应的真实端点用于选择 root 凭据，不会任取第一条 root 连接。Doris 以真实 root 身份执行授权检查。

支持普通单引号密码、单个用户、默认或显式百分号 Host：

```sql
CREATE USER 'app_reader'@'%' IDENTIFIED BY '请替换为强密码';
GRANT SELECT_PRIV ON DWD_人口.人口关系网 TO 'app_reader'@'%';
REVOKE SELECT_PRIV ON DWD_人口.人口关系网 FROM 'app_reader'@'%';
SET PASSWORD FOR 'app_reader'@'%' = PASSWORD('请替换为另一个强密码');
DROP USER 'app_reader'@'%';
```

支持普通前置/中间/尾部注释，不支持可执行注释、多条语句、批量用户、角色语法、密码摘要、外部认证或参数占位符。ALTER USER ... IDENTIFIED BY 由相同语法入口处理，最终是否支持由 Doris 校验。不允许更改 root/admin 或共享元数据维护账号的密码/删除操作。不同 Host 身份不能自动合并；新账号验证实际匹配身份必须为 user@%。

CREATE 后自动登记加密凭据，不会凭空授予业务库权限。GRANT 后为已纳管且在该连接范围内的库建立关联，复用共享对象、血缘和用户返回策略。REVOKE 更新关联并阻止旧会话继续操作。改密后新密码生效，旧连接必须重新连接。DROP 禁用访问并删除该用户名的明文/脱敏例外策略，保留连接和任务记录。

权限变更后旧业务连接需重连（当前实现采取保守的会话失效策略）。连接时应指定已接入数据库；无默认数据库登录的原有 DATABASE_PERMITTED 限制没有扩大修改。

## 任务和恢复

平台新增“账号同步任务”，仅管理员可访问；最多显示最近 200 条。

- 同步成功：客户端 SQL 返回成功。
- 同步待重试：Doris 已成功，平台同步失败；客户端明确提示不要重复执行原 SQL。后台每轮间隔 10 秒重试至多 20 项，可手动重试。此间受影响账号禁止访问。
- 待补充凭据：对未登记用户授权后，无法读取其密码；请登记凭据，再重试同步。
- 待接入数据库：账号与已有纳管库已同步，但存在未纳管库；管理员先通过初始化模块完成安全接入，再重试。不自动把未纳管表当作明文表放行。
- 结果待核实：数据库执行发生超时、连接中断或服务重启，绝不自动重放原 SQL。管理员“按实际状态恢复”读取实际凭据/授权恢复同步，不代表确认原 SQL 必然成功。DROP 需确认真实用户已不存在。
- Doris 拒绝：记录错误码和 SQLState，不保存原 SQL 或明文密码。

任务持久化在 account_lifecycle_tasks；账号可用状态与会话代际在 account_lifecycle_states。其余复用现有连接、账号库关联、权限快照和策略表。密码使用现有主密钥加密，成功/明确拒绝后清理任务临时密码。操作不具备跨 Doris 与网关存储的原子事务；未同步完成或结果未知时隔离账号，依靠持久化任务恢复。

直连 Doris 的 CREATE/改密/删除没有自动凭据捕获；原有已接入用户权限快照刷新仍保留。不能把本次网关内 SQL 闭环理解为数据库外部用户生命周期全自动同步。

## 验证与部署

隔离验收入口 3312/18086，使用 gateway_multi_acceptance_20261014 合成数据。测试脚本：

- scripts/account-lifecycle-e2e.cjs：创建、表/库授权、撤权、改密、删除、新旧连接隔离、注释、任务不泄露密码。
- scripts/account-lifecycle-fault-test.cjs：停止隔离代理，Doris 成功后同步失败，再恢复代理仅重试同步。
- scripts/multi-user-e2e.cjs：指定 ACCEPTANCE_PROXY_PORT=3312、ACCEPTANCE_ADMIN_PORT=18086，回归原有 13 组多用户/血缘行为。
- scripts/mapping-ui-local-test.cjs：本地浏览器模拟测试，默认规则与中文策略、表单布局和交互。

镜像标签均为 accounts-20261015；构建目录 /data/gateway-account-build。发布脚本先冷备份三个服务的配置和数据，再替换容器，未使用 Compose，未改变 Doris 默认副本数。

正式入口仍为 18080、业务端口 3308；内部 worker 18082。发布备份 /data/gateway-accounts-backup-20261015，旧容器后缀 -pre-accounts-20261015 保留。回退应先停止新容器并另行保存发布后配置，再使用冷备份和旧镜像恢复；不要在 H2 正被进程使用时直接覆盖数据文件。真实 Doris 的用户和授权变化不会随网关文件回退而撤销，必须单独核对。

本次还包含此前尚未发布的默认规则展示、中文策略名称及字段映射表单布局修正。规则匹配语义和既有脱敏配置不变。

## 实际发布验收

已发布到 192.168.232.132，三个正式容器均为 healthy，版本 2026.10.15-accounts.1。正式登录、退出及原有 9 条账号关联回归通过。3308 上新建一次临时用户、授权人口表并查询确认脱敏，共耗时 648ms（单次功能验收，不是性能承诺）；随后删除该测试用户，并验证已有连接不能继续查询。真实敏感结果未输出。

Maven 共发现 86 项测试，实际执行 61 项全部通过，25 项环境依赖测试跳过。隔离账号生命周期、故障恢复、外部账号补凭据和既有 13 组多用户血缘回归通过。正式浏览器验证四类默认规则、中文策略、字段规则表单及账号同步任务菜单通过。

当前保守会话代际策略在代理重启或管理端手动完成同步后，可能要求该用户的首个业务连接额外重连一次。此行为防止旧凭据连接继承新账号状态，尚未扩展为完整前端认证事件集成。现有正在执行中的 SQL 不承诺被授权变更强制取消；后续访问重新校验。
