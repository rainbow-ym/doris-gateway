# 多集群管理平台发布与使用说明

## 已发布状态

2026-10-15 已发布到 192.168.232.132。平台版本 `2026.10.15-clusters.1`。

- 管理入口：http://192.168.232.132:18080/login.html。
- 平台账号：沿用原管理端管理员账号和密码，不是 Doris 的 root/1。首次启动将管理员密码以 BCrypt 哈希保存到平台数据库；页面可修改密码并使已有会话失效。
- 现有业务入口：192.168.232.132:3308，用户名、密码、逻辑库名称和已有策略保持不变。
- 默认集群管理实例：127.0.0.1:18082，仅本机访问；网关内部控制和血缘接口直连该实例，不经过平台转发。
- 镜像：`doris-security-gateway-platform:clusters-20261015`、`doris-security-gateway-admin:clusters-20261015`。SQL 网关复用 `doris-security-gateway:multi-user-20261014`，本次没有改动其二进制。

## 隔离方式

采用统一管理平台、每集群独立管理实例、独立管理数据库和独立网关。既有单集群表结构保持复用，不是在共享表里仅依赖页面筛选。平台注册表使用 cluster ID 和实例的持久 UUID；请求必须指定已登记的集群，实例身份不匹配或不可用时拒绝，不回退其他集群。

连接凭据、表目录、血缘、权限快照、用户策略、字段识别规则和任务记录分别保存在所属实例的管理数据库。平台仅保存集群登记及加密后的实例管理凭据。不同集群必须使用独立数据目录、端口和令牌，不可复制同一个管理库当成新集群；复制实例 UUID 会被拒绝登记。

平台故障影响统一管理页面，但网关仍直接使用各自管理实例。单个管理实例故障会使对应集群按原有安全策略拒绝相关请求。共享主机的 CPU、磁盘、网络故障仍可能影响多个实例；本版本未提供高可用集群或物理资源完全隔离。

## 管理员认证

提供登录、退出、30 分钟空闲过期、修改密码、登录限速、CSRF 防护和后台 ADMIN 权限检查。无普通业务用户登录管理平台的入口。网关内部服务认证与浏览器会话独立；浏览器拿不到管理实例密码。

当前保留内网 HTTP 地址，HTTP 本身不加密凭据及会话。跨不可信网络使用前必须配置 HTTPS 入口，并将平台配置 `PLATFORM_COOKIE_SECURE=true` 后重建平台容器。没有部署 TLS 证书、SSO、MFA 或多管理员管理功能，不能据此宣称已满足全部安全合规要求。

## 初始化与增量接入

进入集群后，选择“初始化与增量接入”。上传 UTF-8 CSV，表头为 `username,password`，可选 `databasePattern`。每次 1—200 个账号、文件不超过 1 MB。含逗号或双引号的密码须按 CSV 引号规则编码。页面只接受文件，不回显密码。

流程：上传并验证 → 查看任务明细 → 确认接入 → 查看成功或失败项。验证在后台执行，不修改 Doris 授权。空数据库范围默认 `%`，统一排除 information_schema、mysql、__internal_schema、sys、performance_schema，只发现该账号可见的数据库。

预览只展示账号、数据库、状态和说明。未确认的加密凭据一小时后由清理任务移除；成功保存连接后删除导入暂存凭据。相同端点和用户的现有连接会复用；密码或扫描范围冲突拒绝覆盖。重复确认运行中任务被拒绝；重试跳过已经成功的账号。部分失败不会自动删除其他成功账号，也不会回滚已发生的 Doris 操作。

建议先用元数据维护账号接入目标数据库，再导入其他用户。如果先以权限不足账号初始化共享目录，后续需要处理原接入任务，不会借用其他用户权限自动越权补全。

## 外部创建的新表

选择元数据维护连接进行扫描 → 在“集群字段保护”核对敏感字段 → 到“运行与血缘”勾选待纳管表 → 批准本页选中表。成功后发布保护规则、激活表并更新该库相关用户的权限投影。真实 SQL 权限最终仍由各自 Doris 用户校验。

此类表作为外部源表纳管，不伪造未捕获的历史 SQL 血缘。默认不会自动批准未知新表。批量批准每次最多 50 张，逐表返回结果；大批量操作可能耗时，应分批执行。

## 字段识别规则

在“字段识别规则”新增规则，例如字段名精确匹配“关系人证件号码”，敏感类型选择“证件号码脱敏”。支持精确、前缀、后缀匹配，库/表可填精确名称或 `*`。仅影响当前集群。

试运行不会保存，展示命中数量和最多 100 条样例。保存后重新扫描生成建议，再确认和发布。人工确认的策略不被自动扫描覆盖；删除识别规则不会解除已发布的保护。显式 SECURITY 注释优先于名称识别；同级规则冲突则拒绝该次识别，不随意选择。精确匹配优先于宽泛匹配。

用户明文、脱敏和拒绝返回仍在“用户与返回策略”中配置。字段识别与用户返回动作分离。现有姓名、证件号等算法参数保持复用，本次没有新增任意算法编辑器。

## 页面变化

集群列表作为入口；登录后可登记、编辑或解除集群登记。解除登记只删除平台关联，不停止网关，不删除其管理数据，也不修改 Doris。

字段、受管对象、SQL 同步任务、血缘事件、策略版本、审计列表使用服务端分页，每页 25 条。初始化任务、字段规则编辑、账号权限和血缘来源使用详情抽屉，关闭后保留原页面。字段和对象批量选择限定本页，不声称跨页已全选。小型配置列表仍使用现有列表组件。

## 新增另一个集群

第一版不通过网页远程操纵 Docker。使用已发布镜像，在网关服务器执行：

```bash
CLUSTER_ID=cluster-b \
CLUSTER_ADMIN_PORT=18085 \
CLUSTER_GATEWAY_PORT=3309 \
CLUSTER_GATEWAY_BIND_ADDRESS=192.168.232.132 \
bash /data/gateway-clusters-build/scripts/provision-cluster-instance.sh
```

确保端口未占用。脚本创建独立目录 `/data/doris-gateway-clusters/cluster-b`，生成独立控制账号、主密钥及内部令牌；配置文件仅 root 可读。该脚本不使用 Compose，遇到已有目录或容器会拒绝覆盖。已使用该脚本在 132 的独立测试端口创建全新实例，并通过首次接入、账号同步及脱敏查询验收；不同环境仍应先在测试端口验证。

然后在平台“登记集群实例”填写集群名称、`http://127.0.0.1:18085`、实例管理账号密码（见该目录的 admin.env），以及业务网关地址。登记前校验实例身份。跨服务器管理实例必须提供 HTTPS 地址；本机回环允许 HTTP。进入集群后再添加实际 Doris 连接并执行初始化。

## 启动配置与备份

- 平台：`/data/doris-security-gateway-platform/platform.env` 和 `data/`；启动脚本 `/data/gateway-clusters-build/scripts/run-platform-docker.sh`。
- 现有集群管理实例：`/data/doris-security-gateway-admin/admin.env` 和 `data/`。
- 现有网关：`/data/doris-security-gateway/gateway.env`、`conf/`、`logs/`。
- 发布冷备份：`/data/gateway-clusters-backup-20261015`。
- 旧容器：`doris-security-gateway-pre-clusters-20261015`、`doris-security-gateway-admin-pre-clusters-20261015`。

修改容器环境配置后要重建相应容器；修改平台密码应使用页面，不是重复编辑首次启动密码。保存平台主密钥和每个实例主密钥，丢失后无法解密已保存凭据。

回退前先停止新平台、管理实例和网关，另存当前配置及管理库，再成套恢复冷备份的管理库、代理配置和两个 env 文件，恢复旧容器名称并启动。不要让旧程序直接读已升级管理库。回退不撤销 Doris 数据操作，且会丢失冷备份后的网关配置变更。
