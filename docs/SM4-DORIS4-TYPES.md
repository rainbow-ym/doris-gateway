# Doris 4 SM4 导出类型适配

本次基线 main 0b44c33；仅升级网关，不修改 Doris、业务表和既有保护策略。

## 返回规则

- 加密开关关闭：沿用现有查询处理。
- 加密开启：普通列保留 JDBC 原生值、列类型和顺序；不再使用“文本、整数、定点数”全结果白名单。
- 受保护列统一以 VARCHAR 返回脱敏文本，NULL 保留 NULL。保持列名及来源名称，清除原数值精度、主键、自增等不适用于脱敏文本的元数据。业务若强制按日期或数值读取这些列，需要改为读取文本。
- 原值从底层 JDBC 取原始文本；二进制用 getBytes，并以 Base64 恢复到 CSV。尽量避免日期、长整数在 Java 中二次转换造成信息损失。
- 普通列值不会发送到 Worker。严格模式仅发送其摘要；可编辑模式仅校验受保护显示内容。每次查询只保存批次元数据和回执，不保存逐行原值或密文副本。
- 新捕获协议 ROW_TYPED_V1 / 文件内部版本 5。Worker 继续解密版本 2、3、4；旧文件不会自动获得新的编辑权限。新 Proxy 要求新 Worker，三组件必须配套升级。

## 类型与验证范围

| 类型/表示 | 行为 | 本地验证 |
| --- | --- | --- |
| CHAR/VARCHAR/STRING | 原文本、Unicode、换行按 CSV 转义 | 已测编码 |
| 整数/LARGEINT/DECIMAL | 保持 BigInteger/BigDecimal 或驱动文本，不转 double | 已测大整数、小数精度 |
| FLOAT/DOUBLE/BOOLEAN | 普通列保留驱动数值；保护列返回脱敏文本 | 已测缓冲及特殊浮点编码 |
| DATE/DATETIME/TIME | 普通列保留驱动值；保护原值优先 getString | 已测日期、纳秒值、长 TIME 文本编码 |
| TIMESTAMPTZ | 不额外转换时区；按驱动返回表示 | 已测带偏移时间编码，未测 Doris 实机 |
| ARRAY/MAP/STRUCT/JSON/VARIANT/IP | 驱动返回 String 时不再解析或改写其内容 | 已测嵌套 JSON 文本；未逐项实机验证 |
| VARBINARY/byte[] | 普通列复制字节，保护原值解密为 Base64 | 已测含零及非 UTF-8 字节 |
| 驱动专属 Array/Blob/Clob 或未知对象 | 明确报告列位置、列名及类型，不调用任意 toString 猜测内容 | 已测拒绝未知对象 |
| BITMAP/HLL/QUANTILE_STATE/聚合状态 | 由 Doris 决定能否直接投影及其返回表示；网关不解释内部状态 | 未做实机验证 |

参考：[Doris 4 类型总览](https://doris.apache.org/docs/4.x/sql-manual/basic-element/sql-data-types/data-type-overview/) 和 [MySQL 兼容说明](https://doris.apache.org/docs/4.x/query-data/mysql-compatibility/)。Doris 的类型支持不等于所有 MySQL 驱动都能无损读写该类型。测试不能替代真实 Doris 4、驱动及业务导出的联合验收。

## CSV 规则及边界

开启普通列编辑后，可增删普通列、修改普通列名/值和排列顺序；保留受保护列名及显示内容，__gateway_sm4 仍须是最后一列。保护列和密文不可修改。保护显示值相同的行交换密文仍可能无法区分，不能当作业务行身份认证。

严格模式要求文件内容与网关采用的文本表示一致；导出器对日期、浮点、布尔或二进制改格式会触发拒绝。可编辑模式不校验普通列，避免这类普通列格式差异影响解密。

CSV 本身无类型：解密不会自动把单元格变成数据库日期、数值对象；NULL 和空字符串在 CSV 中均显示为空。保留现有防公式注入转义规则，危险前缀可能添加单引号。Excel 自动改写长整数、日期或保护内容仍可能破坏文件，应使用不自动转换字段的 UTF-8 CSV 工具。

保留原有限额：最多 1000 行（账号可配置更低）、255 个业务列、512 KiB 收集缓冲、1 MiB 捕获请求、768 KiB 密文总量、30000 字符单行密文。超限整次查询失败，不截断、不退回原文。新增类型不表示取消容量限制。

## 内网验收

1. 同一业务查询分别关闭/开启 SM4，验证普通列名称、类型、值及行数一致；受保护列变为文本且已脱敏。
2. 使用真实驱动分别执行普通 Statement 和服务端 PreparedStatement，覆盖日期、数值、NULL、复杂文本及大整数。
3. 导出 CSV，增删改普通列后授权解密；检查受保护原值精度。篡改保护内容、密文，或撤销授权后必须失败。
4. 用现有五用户探针测试 20/180/200 行，观察错误、延迟和内存；配置上限 200 时实际返回 201 行必须失败。
5. 若还有不支持类型，保留错误中的列类型、Doris 4 补丁版本、驱动版本及无真实数据表结构。此包未在内网执行部署，不宣称全部 Doris 4 类型和驱动已验证。
