# 可编辑 CSV：自动行编号（ROW_V4）

## 启用与升级

在 SM4 加密导出中编辑对应账号＋逻辑库，勾选“允许编辑普通列后解密”，保存后重新查询导出。
不需要填写业务列名，不要求 SQL 返回证件号或主键；查询只返回受保护列也可以使用。
加密和解密授权默认关闭；新建表单默认选中普通列可编辑，但必须显式保存并开启加密。

升级会把原先设置了 rowKeyColumn 的配置转换成 allowEdit=true 并清空该字段，不修改账号、密钥或文件到期时间。
原先没有指定标识列的配置保持严格模式，需勾选普通列编辑开关后保存。
旧 ROW_V2 文件继续校验全部业务列，旧 ROW_V3 继续校验其原有业务标识；都不能事后变成 ROW_V4。
为兼容旧 API 客户端，旧 rowKeyColumn 参数仍可生成 V3；新管理页面不使用该参数。

## 文件规则

- 普通列可新增、删除、改名、改值和调整顺序，解密输出保留上传文件的普通内容和列顺序。
- 受保护列可以移动，但不能删除、改名、修改显示值。没有额外的不可修改业务编号。
- 最后一列必须是 __gateway_sm4，列名、位置和密文不能修改。
- 表头必须非空且唯一；UTF-8 CSV，最多 1 MiB、255 个业务列、1000 数据行；配置可设置更低行数上限。
- 可整行排序、删行或选取部分行；密文必须跟随记录。不能重复密文行或混合不同查询批次。
- Excel 自动改写受保护值（空格、数字格式等）也可能导致校验失败。NULL 导出为空。
- 修改受保护内容、缺失受保护列、重复密文、混合版本或批次、过期、撤销、权限失效时拒绝整份文件，不下载部分结果。
- 下载结果移除密文列。以公式字符开头的单元格仍进行安全转义。

## 认证边界

ROW_V4 每行包含经过 SM4-GCM 认证的版本、批次编号、批内行号、受保护原值和受保护显示值摘要。
普通内容不参与摘要，因此不能证明编辑后的普通内容与原始业务记录的关联真实性。
尤其两行受保护显示值相同，只交换密文可能无法识别；自动行号不能消除这个边界。
这不是严格防错行模式。不要把允许编辑的导出当作未经改动的业务凭证。

## 配置管理

配置粒度为账号＋逻辑库。可编辑、删除；新增时每行填写一个库，可一次保存 1—100 个库。
任何一个库未有效绑定或参数无效，整批不保存。编辑现有项时账号与库固定，需要其他项请点“新增配置”。

“跟随账号和接入库自动关联”属于当前 Worker，默认关闭。开启后，对当前及后续有效接入的账号＋库组合应用默认值。
默认值分别控制自动加密、自动解密授权、普通列可编辑、行数、期限，保存前明确提示授权范围。
人工配置始终优先，编辑自动项并保存会转成人工配置。修改默认值影响全部自动项，不改人工项。
移除接入关系、禁用账号时自动项失效，恢复有效接入后自动项恢复。关闭自动关联则自动项停止加密及解密。
手动删除保留一条禁用标记，自动关联不会补回；手动新增同一账号＋库可恢复配置。
删除配置不删除历史密文批次或密钥；重新授予授权后，未过期未撤销的历史文件可再次解密。
永久作废某个文件请撤销批次，而不是只关闭权限。

## 独立开关和期限

- 关闭加密：不再生成新密文；保留解密授权时历史文件仍可解密。
- 关闭解密授权或删除配置：拒绝历史文件解密；批次撤销和原账号权限检查仍生效。
- 文件有效期以整数天设置，1—365 天。管理库仍用分钟存储以兼容旧配置。
- 历史不足一天的设置在编辑时显示原分钟数，天数留空则保留，填入天数则只影响新文件。
- 改变配置期限或编辑模式不改变已生成文件的期限和格式。

## 存储和维护

每次 ROW_V4 查询保存一条批次记录、一份加密公共元数据、一条加密审计；不保存原始结果、显示结果或逐行密文副本。
公共元数据包含来源、权限关联、字段定义等，不包含单元格原值；各行密文保存在导出文件中。
密文长度随保护原值数量和长度增长，不承诺固定长度，不截断认证标签。
解密需要对应的 Worker 管理库、账号、原密钥及当前授权，需同时备份数据目录与密钥。
新格式文件不能交给旧 Worker 解密。

每 60 秒最多清理 10000 条过期记录并级联清理批次元数据；过期立即拒绝解密，不依赖清理完成。
SM4_EXPORT_CLEANUP_MS 可调整周期。SM4_EXPORT_AUDIT_RETENTION_DAYS 默认为 0，保留审计；设为 1—3650 才按天清理相关查询加解密审计。
不删除密钥、有效批次、配置审计或业务数据。有效期一年会增加元数据和旧密钥保留时间；审计默认仍会增长。

现有并发限制、查询缓冲限制和运行监测复用，不新建逐行线程池，也不自动增加 JVM 堆。
