# SM4 末行导出核查与修复（2026-10-19）

基线：`dab9223beed3d90e03bb229ffebe1827c0b2da4f`；分支：`fix/sm4-export-completion`。
本次只修改本地代码，没有连接或更改生产服务。

## 已有实现

- 按数据库账号和逻辑库开启，默认关闭；含保护列的查询先缓冲，再返回脱敏数据和最后一行密文，不要求业务额外参数。
- 保持列数和声明类型，密文放入文本列；当前仅支持文本、整数、定点数。其他类型或没有文本列时明确拒绝。
- 最多 1000 行、256 列，原值和显示值缓冲最多 512 KiB，请求最多 1 MiB，密文单元格最多 30000 字符；并发缓冲限制为 2。
- 管理端使用 SM4-GCM，随机 nonce、认证标签与密钥版本；密钥由部署脚本在数据目录生成，不打入 JAR。
- CSV 解密需要独立管理员登录、源账号的解密开关、有效的本实例回执，并重新检查账号凭据版本、来源对象身份和当前字段访问权限。
- 校验表头、行列顺序及完整内容；支持过期、撤销和审计。系统库回执不存原始敏感值。

## 本次修复

1. CSV 无末尾换行时也检查行数、列数；1 MiB 按 UTF-8 字节而非 Java 字符数计算。
2. 权限验证使用经过身份验证的物理库名，修复逻辑库别名导致合法文件不能解密的问题；新密文记录物理库映射，映射变化时拒绝。
3. 若两行脱敏后完全相同，但其待恢复原值不同，捕获和解密均拒绝。单靠内容摘要无法识别这些行的交换；查询需包含稳定唯一标识。相同显示行且原值也相同仍可导出。
4. Proxy 发送完整的 JDBC 列类型列表；管理端验证支持的类型和文本承载列，并将类型写入认证加密的载荷。

升级时应同时更新 Proxy 与 worker。旧 Proxy 缺少列类型信息，会在开启本功能时收到明确错误；默认关闭的账号不受该协议变化影响。既有 V1 文件继续执行原有权限、身份和摘要校验，新增重复行歧义检查。

## 部署前仍须验证

- 本次没有可用 Doris/Proxy 隔离实例，未重新执行真实查询、MySQL 文本/预编译协议、并发及端到端 CSV 解密验收。已有真实测试进度描述不计入本次验证。
- Docker 引擎未运行，且 `Dockerfile.sm4-*` 依赖既有 `release-20261018/19` 基础镜像。本次 JAR 包不是可直接 `docker load` 的完整离线镜像包。
- `scripts/sm4-export-e2e.cjs` 使用固定隔离地址、库名与运行库路径；只应在核实的隔离环境使用，不能直接对生产运行。
- 业务系统必须原样保留最后一行、长文本、空值及行列顺序。VARCHAR 长度限制、固定类型映射、自动分页、导出截断仍可能不兼容，不能保证所有业务系统支持。
- 第一版只接受带表头 UTF-8 CSV，不支持 XLSX。CSV 不能区分 NULL 与空字符串；下载时将公式前缀值加单引号，这是明确的导出格式约定，不是原始 SQL 类型无损往返。
- 解密授权对象是独立管理平台管理员，数据库账号通过配置允许管理员解密其文件。没有业务系统最终用户身份，也没有新增多人员明文权限模型；共用数据库账号不能据此推断实际业务人员。
- 回执撤销只阻止后续解密，不可能收回已下载的明文。审计记录代表服务已生成/返回明文，不能证明浏览器已保存到磁盘。
- 原有安装 README 仍引用 accounts-20261015 镜像归档，而安装器要求 sm4-export-20261019 镜像；组装正式离线包时必须匹配镜像标签、归档说明和校验清单，不能混用旧镜像。
