# 多用户权限与返回策略改造

## 实施边界

复用现有 connections、logical_databases、managed_objects、managed_columns、metadata_columns、lineage_edges、managed_sql_executions 和 audit_log。逻辑库原 connection_id 保留为全局元数据维护账号，不再代表唯一业务账号。新增账号关联、权限快照、用户策略。SHOW/information_schema 额外过滤不在本次范围。

实际 SQL 必须使用会话用户的数据库凭据；关联缺失、控制服务不可用或身份歧义时禁止回退到存储单元账号。连接会话独立持有连接，普通查询、预编译查询及事务使用相同身份。

## 验收

- 两个账号关联同一逻辑库，CURRENT_USER() 与真实账号一致。
- B 库级 SELECT、C 单表 SELECT：新建表后 B 可查询，C 被 Doris 拒绝。
- 撤销权限后，即使缓存存在也不能成功查询。
- B 明文、C 脱敏，交替查询和预编译查询不串用户。
- CTAS 标签共享，用户明文例外不复制给其他账号。
- ALTER/RENAME/DROP 后刷新对象状态，权限按 Doris 实际结果处理。
- 控制服务不可用、账号关联缺失、权限同步失败不能使用 root 代查。
- 旧数据迁移幂等，服务重启后关联、策略和全局血缘保留。

## 使用入口

1. 在“连接与接入”添加真实 Doris 用户连接，发现数据库。已经由其他用户接入的同一端点数据库可关联当前用户，不再重复建立全局表目录。
2. 在“用户与返回策略”检查账号关联，点击“刷新权限”读取当前账号授权快照。
3. 选择用户、逻辑库、具体字段或敏感类型，保存明文、脱敏/加密或拒绝返回策略。后续查询生效；未配置例外时使用全局字段保护。
4. 业务使用该真实账号的同名同密码连接 3308。返回策略不赋予 Doris 权限，底层拒绝的语句仍然拒绝。

## 中间表与一致性边界

- `account_database_bindings`：用户连接与共享逻辑库关联。
- `account_privilege_snapshots`：真实身份、原始授权快照和刷新状态。
- `account_privilege_scopes`：解析后的授权范围。
- `account_object_access`：对象的操作权限投影，供管理展示；不是底层 SQL 的授权替代品。
- `user_output_policies`：用户级明文、脱敏/加密、拒绝返回策略。

共享对象、字段、血缘和执行生命周期沿用原有表。管理端权限刷新周期默认 60 秒（固定延迟，执行耗时另计），界面可手动刷新。实际执行使用当前业务用户的 Doris 连接，快照过期不允许借用 root 权限。

网关捕获的受支持 DDL/DML 在返回成功前完成相应登记；映射失败的对象保持不可访问。Doris 数据事务与管理库不构成分布式原子事务，网络结果不明时保留失败状态并核对，不能自动重放数据写入。

## 运维与回退

启动配置保留在 `/data/doris-security-gateway/gateway.env` 和 `/data/doris-security-gateway-admin/admin.env`。两个配置均已启用 `GATEWAY_MULTI_USER_ENABLED=true`，多用户接入后不能关闭该开关，否则不满足用户身份隔离要求。

本次使用的启动脚本位于 `/data/gateway-multi-user-build/scripts/run-docker.sh` 和 `run-admin-docker.sh`。用户安装目录 `/data/doris-security-gateway-package/run-docker.sh` 同步更新为支持多用户开关的版本。脚本在创建容器时读取配置，不使用 Compose；普通重启可使用 `docker restart`，修改环境变量后需重建容器而不是仅重启。

冷备份在 `/data/gateway-multi-user-backup-20261014`，旧容器保留为 `doris-security-gateway-pre-multi-20261014` 和 `doris-security-gateway-admin-pre-multi-20261014`。若需回退，先停止新服务并另存当前配置及管理库，再成套恢复冷备份的管理库、代理配置及两个 env 文件，最后恢复旧容器名称并启动。不要让旧程序直接读新管理库；回退会丢失备份之后的网关配置变更，但不会回滚 Doris 业务数据。

## 已知限制与后续讨论（未实施）

- 外部直接创建的表需要先扫描、确认字段保护，再到“运行与血缘”批准并同步。按外部源表登记，不会凭空补全未经过网关的 SQL 血缘；批准流程的权限展示投影还需手动或周期刷新。
- 用户密码批量导入、批量初始化任务、可维护的字段别名/匹配规则、服务端分页及详情抽屉属于后续方案，本次没有实施。
- UPDATE JOIN、UPDATE 标量子查询以及多用户模式下联邦执行不在本次支持范围，拒绝处理，不自动降级为不受保护执行。
- 授权解析暂未覆盖所有角色/列级/外部目录表达形式，无法确认的投影标为待确认，真实语句继续由 Doris 使用该用户凭据校验。
- 同一实例逻辑库名称不能映射到不同物理端点；端点按配置的主机名和端口比较，不自动认定 localhost 与其他地址等价。
- 全局元数据维护账号不能单独解除关联；当前需要按逻辑库解除接入处理。SHOW/information_schema 不增加过滤。
- 多用户回归主要验证脱敏；未对新用户策略下的所有 AES 返回模式、所有 SQL 语法或完整事务场景作兼容承诺。
