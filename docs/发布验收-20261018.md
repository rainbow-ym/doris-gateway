## 已发现的边界：不能宣称所有设计目标完全达标

- LIMIT ? 参数化查询：直连 Doris 9030 和通过 3308 均报相同语法错误；普通 LIMIT 和 WHERE 参数化预编译通过。本轮不将其认定为网关回归，也未掩盖此失败。
- Doris 专用建表语法：显式 UNIQUE KEY ... DISTRIBUTED BY ... 在网关 MySQL 解析阶段被拒绝；CAST(... AS VARCHAR(...)) 也存在解析限制。此类方言兼容性尚未解决，不能宣称任意 Doris SQL 可透明通过。已验收的是文中明确列出的语句路径。
- 经网关 GRANT/REVOKE 后，受影响账号旧连接会失效并提示重连。重连后正确，不是“任意授权变化都无需重连”。CTAS 新表继承本身没有导致所有账号重连。最初用例未区分这一点，已据实际行为修正测试并单列限制。
- 绕过网关同名同结构删表重建的物理 ID 自动识别仍未接入运行路径；本次发布不改变该未完成项。
- 没有进行大规模压力、长期稳定性、断电/磁盘损坏或分布式事务验收。本次通过不能等同于全场景安全认证。
