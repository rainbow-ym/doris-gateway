# 安全整改进度：第一批保护边界与恢复基础

日期：2026-10-15（北京时间）。状态：开发和隔离验证完成一个批次，未发布正式服务。整个整改路线尚未完成。

后续进展见 [第二批生效快照与发布日志](整改进度-20261016.md)。下述未完成清单记录的是第一批结束时状态。

## 本批改动

- 删除 information_schema 全文豁免。系统对象仍按原约定豁免自身纳管检查，业务表和混合查询继续验证。
- 对 SELECT 表达式中的标量子查询变更暂时执行前拒绝，不再产生零血缘后继续建表；FROM 子查询和原有别名路径保留。
- 暂时拒绝 CREATE OR REPLACE，避免已有视图变更被误判 NOOP；普通 CREATE VIEW 通过真实网关测试。
- CTAS 常量投影也检查真实来源表，不能仅依赖结果字段血缘边。
- 继承前检查全部来源与目标已有策略冲突，不允许无提示覆盖。不同保护类型之间暂不自动判断强弱。
- 表级 schema 扫描在完整读取后事务提交；清理已删除字段元数据和精确用户例外，保留类型级规则；血缘列顺序优先物理 ordinal_position。
- 血缘事件与边在 Spring 本地事务中保存，失败整体回滚、重试可完整写入。
- 结果返回前一次性编译列算法；敏感列的运行规则缺失时拒绝，已开始返回的查询不逐行重新查规则。
- 用户级 AES 初始化补齐密钥环境变量引用、key-id 和列级 AAD；按列区分算法缓存。此处已有参数单元测试，尚未完成实际密钥解密端到端测试及统一编译器重构。
- 短值保留区间重叠时全部隐藏，不再返回原文，修正整数溢出边界。页面电话/地址算法说明同步。
- SQL 执行结果不确定记录为 UNKNOWN，不参与自动成功恢复。没有成功回调的超时 PREPARED 转为 UNKNOWN 并保持阻断。UNKNOWN 人工核实恢复工作流尚未实现，不能通过普通重试直接放行。
