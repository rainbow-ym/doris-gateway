# 中文账号、异常发布恢复、安全升级及下一阶段事务边界

日期：2026-10-17（北京时间）。仅开发与 132 隔离实例验证，未更新正式服务、平台镜像或离线安装包。

## 1. 中文账号

统一单个数据源、批量 CSV、网关账号命令的用户名校验，支持中文等 Unicode 字母和数字，以及 `_ . -`。CSV 不再将格式错误、精确重复、大小写身份冲突合并为同一个错误，提供出错记录序号；不输出密码。

真实 Doris 中文账号验证了单个接入、批量接入、原名登录、预编译脱敏和越权拒绝。另用中文账号验证 CREATE、授权、撤权、改密、删除全流程，测试账号已清理。

边界：当前网关存储限制仍为 128 个 UTF-16 单元，大小写冲突仍明确拒绝；这不是声称覆盖 Doris 所有合法用户名、Host 规则、认证插件。服务端 Unicode 用户配置仍需允许相关名字。

## 2. 异常发布核实恢复

- 版本历史中为 APPLYING、RECOVERY_REQUIRED、RECOVERING 提供“核实恢复”入口，中文显示恢复状态。
- 先预览，再携带预期生效版本确认。版本已变化时拒绝过期确认。
- 恢复到当前已生效快照的规则，读回校验后结束故障发布；不会激活失败候选、覆盖管理员草稿或重放业务 SQL。
- 首次发布没有生效快照时只恢复发布前规则，仍不允许业务把未知保护状态当作正常状态。
- 恢复失败保持阻断；重复提交已完成恢复幂等返回。本地恢复状态与审计在事务中提交。

隔离 H2 注入未完成发布并重启：验证了无认证拒绝、阻止覆盖发布、Proxy 规则缺失时仍按生效快照脱敏、过期确认拒绝、恢复读回与再次发布、重复恢复及审计，共 5 组。单元测试另覆盖恢复失败重试、恢复中断、首次发布和审计落库失败。

恢复仅处理策略发布，不自动证明 UNKNOWN 业务 SQL 成功，也不擅自恢复被阻断的业务对象。没有发布日志的历史孤立版本不做猜测恢复。前端脚本语法检查通过，尚未做浏览器交互验收。

## 3. 安全升级开发工具

文件：`packaging/clean-install/safe-upgrade.sh`、`safe-upgrade.py`、`SAFE-UPGRADE.md`。

独立 host 网络 worker/Proxy 部署采用：维护窗口确认 → 停平台与业务入口 → 冷备 → 保留旧容器 → 回环地址隔离启动 → 校验所有逻辑库与规则 → 业务验证 → 显式放行。无需 Compose；需要 Python 3 标准库。

- 旧版没有快照：只有运行规则等于已确认配置才初始化，禁止顺带发布不同草稿。
- 已有完整快照：必须与实际运行规则一致。
- 已有快照但缺字段基线：拒绝自动用草稿替换，要求先人工复核并显式发布。
- 放行前支持恢复原容器和冷备；进入 ACCEPTING 后禁止自动恢复旧冷备，避免覆盖新配置。
- 冷备恢复使用独立临时目录完成复制后改名，复制失败不会将半份数据库视作已恢复；失败现场保留。

实际隔离演练通过：stage 后预编译脱敏、显式 rollback 与回退后脱敏、重新 stage + accept 后脱敏、注入容器无法启动后自动回退及查询验证。最后一种为进程启动失败，不是所有磁盘/网络故障均已验证。另有 2 项无 Docker 测试验证复制失败重试、幂等回退、放行后拒绝回退。

限制：演练使用 `--no-platform` 独立实例，尚未实际演练平台停止/恢复；不支持滚动升级、共享 H2、多 worker 并发、任意版本降级。备份和状态文件包含凭据，仅限本机管理员读取，未额外加密。平台镜像不会由本工具升级。该工具尚未合入正式离线安装包。

## 4. 下一阶段已推进：事务边界的最小安全措施

对应自查 F10：StandardDatabaseProxyConnector 在执行前检查会话自动提交和事务状态。`BEGIN / START TRANSACTION` 内，或 `autocommit=0` 时，拒绝 DDL 与非 SELECT 的 DML，返回中文说明及 SQLSTATE `0A000`；不会先执行再报告不支持。

普通查询保持原路径。这不代表已经支持事务内查询的一致性快照，也不改动 Doris 副本数。账号 DCL 独立处理路径不属于本批事务门禁覆盖范围。

真实网关新增 3 组验证：

1. BEGIN 内带注释 CTAS、INSERT SELECT、预编译 DELETE 拒绝，Doris 没有新增目标表；ROLLBACK 后正常脱敏。
2. 关闭自动提交时预编译写入拒绝；恢复自动提交后查询正常。
3. 自动提交 CTAS 正常建表并继承脱敏，随后正常删除测试表。

这是限制不安全用法，不是实现 Doris 与网关元数据的分布式事务。对象代次、DDL 执行后结果不确定、持久化 outbox、执行后审计失败确认仍需后续工作。
